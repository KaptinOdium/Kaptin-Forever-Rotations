# Kaptin Forever Rotations

One collection of 23 Simia profiles for **WoW Forever**, covering seven classes and levels 1-60. You move the character, choose a target and control positioning.

**[Installation](INSTALL.md)** | **[Class guides](docs/classes.md)** | **[Versions and known issues](docs/release-notes.md)**

Download with **Code > Download ZIP**, then extract it. Install only the classes you want using the two folders below. You need your own compatible Simia loader and its WoW addon already installed.

| Class | Included profiles | Version |
|---|---|---|
| Paladin | Protection, Retribution, Holy | 2.7.4 / 2.5.7 / 2.3.18 |
| Druid | Bear, Cat, Balance, Restoration and manual Feral | Bear, Cat and manual Feral 2.3.20. Balance 2.3.14. Restoration 2.3.16. |
| Hunter | Beast Mastery, Marksmanship, Survival | 1.0.10 |
| Mage | Arcane, Fire, Frost | 1.0.0 |
| Shaman | Elemental, Enhancement, Restoration | 1.0.4 / 1.0.7 / 1.0.6 |
| Warlock | Affliction, Demonology, Destruction | 1.3.3 |
| Warrior | Arms, Fury, Protection | 1.0.2 |

## Where the files go

- `forever/custom/`: copy your chosen YAML profiles into your **Simia Forever loader's** custom-profile folder.
- `Interface/AddOns/`: copy the matching companion addon folder into your **WoW Forever game's** `Interface/AddOns` folder.
- `Optional/`: advanced compatibility patch for the documented older Warlock host only; not part of normal installation.

Companions register spell/macro variants. They do not assign a personal keyboard layout. Run and confirm Simia's actual AutoBind action or assign keys manually after installing.

This repository contains profiles, custom companions and instructions. Simia itself, personal settings, saved bindings and character logs are not included. See the release notes for compatibility and validation limits.
