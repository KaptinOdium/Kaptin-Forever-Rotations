# Optional compatibility patch

Normal installation does not require these scripts.

`Warlock-Pet-Bridge` is the existing opt-in own-pet engagement patch for **SimulationcraftExtra 12.175 only**. It edits recognized host blocks with backups and refuses other versions. Read its README, validate the installed host, then explicitly opt in only if needed. It does not establish that the client exposes usable pet threat information.

The Hunter dungeon-entry setting uses the normal companion and profile without a host patch. The legacy strict-group installer is not bundled. The unverified automatic Warlock ground-targeting experiment is also not configured or installed by this collection.
